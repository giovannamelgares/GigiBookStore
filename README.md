# GigiBookStore

Projeto de livraria online desenvolvido com Java e Spring Boot.

## Funcionalidades

* Cadastro de usuários
* Login
* Cadastro de livros
* Edição e exclusão de livros
* Sistema de favoritos
* Controle de permissões entre administrador e cliente

## Regras de negócio

* Apenas administradores podem cadastrar, editar e excluir livros.
* Clientes podem visualizar e favoritar livros.
* Cada usuário possui um perfil de acesso.
